# Hosted with harvest.je

If you want the simplest route, use [harvest.je](https://harvest.je).

## Best for

- teams who want to start quickly
- stores without internal server skills
- users who want commercial support

## Typical setup steps

1. Create your hosted account.
2. Add your store details.
3. Invite your team.
4. Start using tasks, customers, and orders.
