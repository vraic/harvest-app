# Self-hosted with Kamal

If you want full control over hosting, self-hosting is a good fit.

## Recommended approach

Use **Kamal** to deploy Harvest to your own server.

## Typical steps

1. Choose a hosting provider and create a server.
2. Set up your database and environment settings.
3. Deploy with Kamal.
4. Add your domain and HTTPS.
