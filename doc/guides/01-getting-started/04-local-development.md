# Local development

Use local development when you want to test Harvest on your own machine.

## Quick start

1. Download the [Harvest GitHub repository](https://github.com/vraic/harvest-je).
2. Run `bin/setup`.
3. Start the app with `bin/dev`.
4. Open the local URL shown in your terminal.

## When to use this path

- trial runs before a real deployment
- internal demos
- contributing to the project
