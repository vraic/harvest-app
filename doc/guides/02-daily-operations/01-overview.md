# Daily operations

This section shows the simplest day-to-day routine for using Harvest.

## Suggested daily routine

1. Check your [dashboard and notifications](/guides/daily-operations/dashboard-and-notifications).
2. Review and update [tasks and work planning](/guides/daily-operations/tasks-and-work-planning).
3. End the day by reviewing [reports](/guides/daily-operations/reports).
