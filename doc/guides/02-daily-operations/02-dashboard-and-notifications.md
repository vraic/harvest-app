# Dashboard and notifications

Your dashboard is the best place to begin each day.

## What to check first

- overdue or urgent tasks
- new order activity
- reminders related to customers, suppliers, or compliance

## Team habit

Start each shift with a short dashboard check, then move straight into task planning.
