# Account offboarding

Offboarding should be intentional, auditable, and policy-aware.

## Action types

- **Archive**: remove active access while preserving record history.
- **Anonymise**: remove personal data while keeping non-identifying history.
- **Permanent delete**: remove record completely where permitted.
